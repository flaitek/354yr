## Суть приложения

**Habit Streak** — трекер привычек с геймификацией:

- **Отметка привычек** — тап по кнопке отмечает выполнение за день, начисляет очки (+10) и увеличивает серию (streak)
- **Прогресс-кольцо** — визуальный индикатор выполнения всех привычек за день (процент + счётчик)
- **Экономика очков** — за выполнение копятся очки; можно тратить на «заморозки» (50 очков)
- **Заморозки** — спасают серию от сброса, если привычка не выполнена к концу дня
- **Завершение дня** — сбрасывает отметки, применяет заморозки/сбросы серий, даёт бонус +20 за идеальный день
- **Управление привычками** — добавление с выбором эмодзи, удаление долгим нажатием

## Технологический стек

- **Flutter** (Dart) — кроссплатформенный UI-фреймворк
- **Material 3** — тёмная тема, `ColorScheme.fromSeed`
- **StatefulWidget + setState** — локальное управление состоянием (без внешних пакетов)
- **CustomPainter** — кастомная графика: прогресс-кольцо, снежинка, пламя, монета, луна, плюс, галочка
- **dart:math** — тригонометрия для отрисовки (дуги, лучи снежинки, cos/sin)
- **Анимации** — `AnimatedContainer`, `AnimatedOpacity`
- **Диалоги** — `showDialog` + `StatefulBuilder` для формы добавления и подтверждения удаления
